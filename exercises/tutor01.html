Convert the following numbers to unsigned decimal integer?

  1. \(1011\;0101_2 :\;\)

  2. \(17F_{16} :\;\)

  1. \[ \begin{aligned} 10110101_2 &= 1\times2^0 + 0\times2^1 + 1\times2^2 + 0\times2^3 + 1\times2^4 + 1\times2^5 + 0\times2^6 + 1\times2^7 \\ &= 1 + 0 + 4 + 0 + 16 + 32 + 0 + 128 \\ &= 181 \end{aligned} \]
  2. \[ \begin{aligned} 17F_{16} &= F\times16^0 + 7\times16^1 + 1\times16^2 \\ &= 15 + 7\times16 + 256 \\ &= 383 \end{aligned} \]

Convert the following 8-bit numbers to signed decimal integer?

  1. \(1011\;0101_2 :\;\)

  2. \(0011\;1100_2 :\;\)

  3. \(7F_{16} :\;\)

  4. \(9C_{16} :\;\)

  1. The MSB is 1, then the number is negative. So, we convert the number to positive (using 2’s complement)

One’s complement = \(01001010_2\)

Two’s complement = \(01001010_2 + 1 = 01001011\)

\[ \begin{aligned} 0100\;1011_2 &= 1\times2^0 + 1\times2^1 + 0\times2^2 + 1\times2^3 + 0\times2^4 + 0\times2^5 + 1\times2^6 + 0\times2^7 \\ &= 1 + 2 + 0 + 8 + 0 + 0 + 64 + 0 \\ &= 75 \end{aligned} \] Therefore, \(1011\;0101_2\) = -75

  1. \[ \begin{aligned} 0011\;1100_2 &= 0\times2^0 + 0\times2^1 + 1\times2^2 + 1\times2^3 + 1\times2^4 + 1\times2^5 + 0\times2^6 + 0\times2^7 \\ &= 0 + 0 + 4 + 8 + 16 + 32 + 0 + 0 \\ &= 60 \end{aligned} \]

  2. Since the MSB is 7 less than 8, then the number is positive. \[ \begin{aligned} 7F_{16} &= F\times16^0 + 7\times16^1 \\ &= 15 + 7\times16 \\ &= 127 \end{aligned} \]

  3. Since the MSB is 9, the number is negative.

One’s complement of C is F - C = 3

One’s complement of 9 is F - 9 = 6

Two’s complement of 9C is \(63_{16} + 1 = 64_{16}\)

\[ \begin{aligned} 64_{16} &= 4\times16^0 + 6\times16^1 \\ &= 4 + 6\times16 \\ &= 100 \end{aligned} \] Then, \(9C_{16}\) = -100
