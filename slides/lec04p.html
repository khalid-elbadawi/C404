🚀 The Journey: Sequential to Conditional

From Linear Execution to Program Logic

Sequential vs Branching Execution

Sequential Execution

mov  ax, 1     ; Step 1
add  ax, 2     ; Step 2  
mov  bx, ax    ; Step 3

Predictable: Each instruction follows the next

Branching Execution

mov  ax, 1     ; Step 1
jmp  skip      ; Jump!
add  ax, 2     ; Skipped
skip:
mov  bx, ax    ; Step 3

Dynamic: Execution path can change

The Instruction Pointer - Your Program’s GPS

Key Concept:

The Instruction Pointer (EIP in 32-bit, RIP in 64-bit) always points to the next instruction to execute

Instructions that modify EIP:

  • JMP - Unconditional jump
  • Jcc - Conditional jumps
  • LOOP - Loop instruction
  • CALL, RET - Function calls

Address Types:

Relative Offset:

EIP = EIP + displacement

Absolute Offset:

EIP = target address

🎯 The JMP Instruction

JMP - Unconditional Transfer

Syntax:

JMP  <target>

Target can be:

  • Label (most common)
  • Register (absolute)
  • Memory location (absolute)
  • Immediate value (relative)

Example - Simple Jump:

        mov   ax, 5
        jmp   skip      ; Jump over next line
        mov   ax, 10    ; This is skipped
skip:   
        add   ax, 1     ; AX = 6 (not 11)

💡 Remember: Labels are converted to relative offsets by the assembler

Jump Range Formats

Format Range Description Usage
rel8 -128 to +127 bytes Short jump Small loops
rel16 Within segment Near jump (16-bit) Legacy code
rel32 Within segment Near jump (32-bit) Modern code

🎯 Assembler Magic: Automatically chooses the smallest encoding that works!

🔄 The LOOP Instruction

LOOP - Assembly’s Built-in Counter

Syntax:

LOOP  <target>

How it works:

  1. Decrements ECX
  2. If ECX ≠ 0, jumps to target
  3. If ECX = 0, continues to next instruction

Simple Example:

        mov   ecx, 3    ; Loop 3 times
top:    
        ; loop body here
        loop  top       ; ECX-- and jump if ≠ 0

⚡ Key Point: Always set ECX before using LOOP!

LOOP Example: Powers of 2

        mov   ax, 1     ; Start with 1
        mov   ecx, 4    ; Repeat 4 times
top:
        add   ax, ax    ; Double AX
        loop  top       ; ECX-- and loop
        ; Final result: AX = 16

Trace:

Iteration AX ECX
Start 1 4
1 2 3
2 4 2
3 8 1
4 16 0

Real Example: Sum of Powers of 2

Problem: Compute \(1 + 2 + 4 + 8 + \cdots + 1024 = \sum_{k=0}^{10} 2^k\)

        section .data
varS:   dd      0

        section .text
_main:
        mov     eax, 1        ; First element (2^0 = 1)
        mov     ebx, eax      ; Initialize sum with first element
        mov     ecx, 10       ; Loop counter for remaining terms
top:
        add     eax, eax      ; Generate next power: eax *= 2
        add     ebx, eax      ; Add to sum
        loop    top
        
        mov     [varS], ebx   ; Store final result (2047)
        ret

Array Processing Example

Problem: Sum array elements {13, 22, 18, 10, 25}

        section .data
arrX:   dw      13, 22, 18, 10, 25
ARRSIZ  equ     ($ - arrX) / 2          ; Calculate array size
sum:    dw      0

        section .text
_main:
        mov     esi, arrX     ; ESI points to array
        mov     ecx, ARRSIZ   ; Set loop counter (5)
        xor     ax, ax        ; Clear sum (AX = 0)
L1:
        add     ax, [esi]     ; Add current element
        add     esi, 2        ; Move to next element (word = 2 bytes)
        loop    L1            ; Continue loop
        
        mov     [sum], ax     ; Store result (88)

Nested Loops Challenge 🤔

Problem: How to implement nested loops?

for (int i = 100; i != 0; i--)
    for (int j = 50; j != 0; j--)
        // inner loop body

Challenge: LOOP instruction uses only ONE counter (ECX)!

Solution: Save and restore the outer loop counter

Nested Loops Solution

        section .bss
count:  resd    1         ; Storage for outer loop counter

        section .text
        mov     ecx, 100      ; Outer loop: 100 iterations
OUTER:
        mov     [count], ecx  ; Preserve outer counter
        mov     ecx, 50       ; Inner loop: 50 iterations
INNER:
        ; ... inner loop body ...
        
        loop    INNER         ; Inner loop control
        mov     ecx, [count]  ; Restore outer counter
        loop    OUTER         ; Outer loop control

💡 Future Enhancement: We’ll use the runtime stack for better solutions!

🔍 Testing and Comparing

Setting Up for Decisions

The TEST Instruction

Syntax:

TEST  <destination>, <source>

Function:

  • Performs implied AND operation
  • Sets flags but doesn’t store result
  • More efficient than AND + CMP

Common Uses:

test  eax, eax    ; Check if EAX = 0
                  ; ZF = 1 if zero

test  eax, eax    ; Check if EAX < 0  
                  ; SF = 1 if negative

test  eax, 1      ; Check if EAX is odd
                  ; ZF = 0 if odd

The CMP Instruction

Syntax:

CMP  <destination>, <source>

Function:

Performs implied subtraction:

destination - source

Sets ALL flags, but operands unchanged

Example:

mov   ax, 100
mov   cx, 50
cmp   ax, cx      ; Compare AX with CX
                  ; 100 - 50 = 50
                  ; ZF = 0 (not equal)
                  ; CF = 0 (no borrow)
                  ; SF = 0 (positive)

Interpreting CMP Results

Unsigned Comparisons:

ZF CF Meaning
1 * dest = src
0 0 dest > src
0 1 dest < src

Signed Comparisons:

ZF SF OF Meaning
1 * * dest = src
0 0 0 dest > src
0 1 0 dest < src
0 0 1 dest < src
0 1 1 dest > src

💡 Remember: Overflow flag complicates signed comparisons!

⚡ Conditional Jumps

The Jcc Family

Jump Categories

Flag-Based Jumps:

Instruction Condition Meaning
JZ / JE ZF = 1 Jump if Zero/Equal
JNZ / JNE ZF = 0 Jump if Not Zero/Not Equal
JS SF = 1 Jump if Sign (negative)
JNS SF = 0 Jump if Not Sign (positive)
JC CF = 1 Jump if Carry
JNC CF = 0 Jump if No Carry

Unsigned Comparison Jumps

Instruction Condition Meaning
JA CF = 0 && ZF = 0 Jump if Above
JAE CF = 0 Jump if Above or Equal
JB CF = 1 Jump if Below
JBE CF = 1 || ZF = 1 Jump if Below or Equal

🎯 Memory Aid: “Above” and “Below” = Unsigned numbers

Signed Comparison Jumps

Instruction Condition Meaning
JG ZF=0 && SF=OF Jump if Greater
JGE SF=OF Jump if Greater or Equal
JL SF ≠ OF Jump if Less
JLE ZF=1 || SF ≠ OF Jump if Less or Equal

🎯 Memory Aid: “Greater” and “Less” = Signed numbers

Quick Jump Examples

Check if zero:

test  eax, eax
jz    is_zero

Check if positive (signed):

cmp   edx, 0
jg    positive

Check if odd:

test  eax, 1
jnz   is_odd

For loop pattern:

mov   ecx, 0
loop_start:
; loop body
inc   ecx
cmp   ecx, 10
jl    loop_start

🏗️ High-Level Constructs

From C++ to Assembly

Simple IF Statement

C++ Code:

if (x > 2000)
    x = x / 2;

Simple IF Statement

C++ Code:

if (x > 2000)
    x = x / 2;

Assembly Translation:

    mov   eax, [x]      ; Load x
    cmp   eax, 2000     ; Compare with 2000
    jbe   ENDIF         ; Skip if x <= 2000
    
    ; Division setup
    xor   edx, edx      ; Clear high part
    mov   ebx, 2        ; Divisor
    div   ebx           ; EAX = EAX / 2
    mov   [x], eax      ; Store result
ENDIF:

IF-ELSE Statement

C++ Code:

if (value < 10)
    smallCount++;
else
    largeCount++;

Assembly Translation:

    mov   eax, [value]          ; Load value
    cmp   eax, 10               ; Compare with 10  
    jnl   ELSE                  ; Jump if value >= 10
    
    inc   DWORD [smallCount]    ; Increment smallCount
    jmp   ENDIF                 ; Skip else part
ELSE:
    inc   DWORD [largeCount]    ; Increment largeCount
ENDIF:

Logical AND (&&)

C++ Code:

if ((total >= 100) && (count == 10))
    total += value;

Assembly Translation:

    mov   eax, [total]      ; Load total
    cmp   eax, 100          ; Compare with 100
    jl    ENDIF             ; Exit if total < 100
    
    cmp   DWORD [count], 10 ; Compare count with 10
    jne   ENDIF             ; Exit if count != 10
    
    ; Both conditions true
    add   eax, [value]      ; total += value
    mov   [total], eax      ; Store result
ENDIF:

💡 Short-circuit evaluation: Second condition only checked if first is true

Logical OR (||)

C++ Code:

if ((total >= 100) || (count == 10))
    total += value;

Assembly Translation:

    mov   eax, [total]      ; Load total
    cmp   eax, 100          ; Compare with 100
    jge   THEN              ; Execute if total >= 100
    
    cmp   DWORD [count], 10 ; Compare count with 10
    jne   ENDIF             ; Skip if count != 10
THEN:
    add   eax, [value]      ; total += value  
    mov   [total], eax      ; Store result
ENDIF:

Switch Statement

C++ Code:

switch (x) {
case 0:  y = 1;   break;
case 2:  y = 10;  break; 
case 4:  y = 100; break;
default: y = 0;
}

Switch Statement

Assembly Translation:

        mov   eax, [x]        ; Load x
        cmp   eax, 0          ; Test case 0
        je    CASE0           ; Jump if x == 0
        cmp   eax, 2          ; Test case 2
        je    CASE2           ; Jump if x == 2
        cmp   eax, 4          ; Test case 4
        je    CASE4           ; Jump if x == 4
        jmp   DEFAULT         ; Default case
        
CASE0:  mov   ebx, 1          ; y = 1
        jmp   ENDCASE         
CASE2:  mov   ebx, 10         ; y = 10
        jmp   ENDCASE         
CASE4:  mov   ebx, 100        ; y = 100
        jmp   ENDCASE         
DEFAULT:mov   ebx, 0          ; y = 0 (default)
ENDCASE:mov   [y], ebx        ; Store result

FOR Loop Translation

C++ Code:

sum = 0;
for (int i = 1; i < 100; i += 2)
    sum += i;

Assembly Translation:

    xor   eax, eax      ; sum = 0
    mov   ecx, 1        ; i = 1 (initialization)
LOOP_START:
    cmp   ecx, 100      ; Compare i with 100 (condition)
    jge   LOOP_END      ; Exit if i >= 100
    
    add   eax, ecx      ; sum += i (body)
    add   ecx, 2        ; i += 2 (increment)
    jmp   LOOP_START    ; Continue loop
LOOP_END:
    mov   [sum], eax    ; Store result

WHILE Loop Translation

C++ Code:

d1 = 100; d2 = 0; t = 0;
while (d2 <= d1) {
    t = t + 1;
    d1 = d1 - 3;
    d2 = 2*t - 1;
}

WHILE Loop Translation

Assembly Translation:

        mov   eax, 100      ; d1 = 100
        mov   ebx, 0        ; d2 = 0  
        mov   ecx, 0        ; t = 0
WHILE_START:
        cmp   ebx, eax      ; Compare d2 with d1
        jg    WHILE_END     ; Exit if d2 > d1
        
        inc   ecx           ; t = t + 1
        sub   eax, 3        ; d1 = d1 - 3
        mov   ebx, ecx      ; Copy t to ebx
        add   ebx, ebx      ; ebx = 2 * t
        dec   ebx           ; d2 = 2*t - 1
        jmp   WHILE_START   ; Continue loop
WHILE_END:
        mov   [d1], eax     ; Store final values
        mov   [d2], ebx
        mov   [t], ecx

DO-WHILE Loop Translation

C++ Code:

count = 1; sum = 0;
do {
    sum = sum / 2 + count * 2;
    count++;
} while (sum < 1000 || count <= 100);

Assembly Translation:

        mov   ecx, 1        ; count = 1
        xor   eax, eax      ; sum = 0
DO_START:
        ; sum = sum / 2 + count * 2
        shr   eax, 1        ; sum /= 2 (faster than div)
        mov   edx, ecx      ; Copy count
        add   edx, edx      ; edx = count * 2
        add   eax, edx      ; sum += count * 2
        
        inc   ecx           ; count++
        
        ; Check conditions: sum < 1000 || count <= 100
        cmp   eax, 1000     ; Compare sum with 1000
        jl    DO_START      ; Continue if sum < 1000
        cmp   ecx, 100      ; Compare count with 100  
        jle   DO_START      ; Continue if count <= 100
        
        mov   [count], ecx  ; Store final values
        mov   [sum], eax

⚠️ Critical: Signed vs Unsigned

Choose the RIGHT comparison jumps!

For Signed Data:

cmp   eax, ebx
jg    greater    ; Use JG
jl    less       ; Use JL
jge   greater_eq ; Use JGE  
jle   less_eq    ; Use JLE

For Unsigned Data:

cmp   eax, ebx
ja    above      ; Use JA
jb    below      ; Use JB  
jae   above_eq   ; Use JAE
jbe   below_eq   ; Use JBE

Mixing them causes subtle, hard-to-find bugs!

🚀 Performance Tips

  • Use TEST for bit checks - faster than AND when you only need flags
  • Use INC/DEC instead of ADD/SUB 1 when possible
  • Keep frequently used values in registers - avoid memory access in loops
  • Use SHR/SHL for powers of 2 division/multiplication
  • Consider CMOV for simple conditionals - avoids branching overhead

💡 Modern CPUs are smart, but good habits still matter!

🐛 Common Debugging Pitfalls

  • Forgetting to set loop counter before using LOOP
  • Using signed jumps on unsigned data (and vice versa)
  • Not preserving outer loop counter in nested loops
  • Infinite loops due to incorrect exit conditions
  • Wrong jump direction (JG instead of JL)
  • Forgetting to clear high part before division

🎯 Key Takeaways

  1. Control flow enables program logic and decision-making
  2. TEST and CMP set up conditions for jumps
  3. Choose correct jump types - signed vs unsigned matters
  4. All high-level constructs translate to jumps and labels
  5. Practice makes perfect - start with simple examples
