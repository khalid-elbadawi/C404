🧮 Arithmetic Operations

The Building Blocks of Computation

INC & DEC Instructions

Syntax

INC <operand>  ; Add 1
DEC <operand>  ; Subtract 1

Example

mov eax, 5
inc eax        ; EAX = 6
dec eax        ; EAX = 5

🎯 Think of it as: count++ and count-- in C++

ADD & SUB Instructions

ADD <dest>, <source>  ; dest = dest + source
SUB <dest>, <source>  ; dest = dest - source

📋 Rules to Remember:

  1. Both operands must be same size
  2. No memory-to-memory operations
  3. EIP/RIP cannot be destination

Valid Combinations

add reg, reg   ✅
add reg, mem   ✅
add reg, imm   ✅
add mem, reg   ✅
add mem, imm   ✅
add mem, mem   ❌

🎭 NEG Instruction - The Sign Flipper

NEG <operand>  ; operand = -operand

How it works:

Two’s complement conversion

Animation Example:

mov eax, 42    ; EAX = 42
neg eax        ; EAX = -42

mov ebx, -100  ; EBX = -100  
neg ebx        ; EBX = 100

💡 Intel’s Secret: NEG = 0 - operand

🚀 Hands-On: Arithmetic Expressions

Let’s translate C++ to Assembly!

Example 1: Simple Assignment

C++ Code

b = a + 1;

Assembly Solution

mov eax, [a]    ; Load a
inc eax         ; Add 1
mov [b], eax    ; Store in b

⚠️ Common Mistake:

add [a], 1      ; DON'T modify original!
mov eax, [a]
mov [b], eax

Example 2: Expression Evaluation

C++ Code

c = 2 * (a + b) + 10;

Assembly Solution

mov eax, [a]      ; Load a
add eax, [b]      ; a + b
add eax, eax      ; 2 * (a + b)
add eax, 10       ; + 10
mov [c], eax      ; Store result

🎯 Strategy: Break complex expressions into simple steps!

🏁 Status Flags - Your Program’s Mood Ring

The Flag Register

Key Flags:

  • CF - Carry Flag (unsigned overflow)
  • OF - Overflow Flag (signed overflow)
  • ZF - Zero Flag (result is zero)
  • SF - Sign Flag (result is negative)
  • PF - Parity Flag (even bits)
  • AF - Auxiliary Flag (BCD carry)

When They Matter:

add al, bl     ; All flags affected
inc eax        ; All except CF
mov eax, ebx   ; No flags affected

Carry Flag in Action

Unsigned Overflow Example:

     01000001  (65)
+    11000010  (194)
     --------
CF=1 00000011  (3) <- Wrong! Should be 259

💡 For unsigned arithmetic: Watch CF for errors!

Overflow Flag in Action

Signed Overflow Example:

     01000001  (+65)
+    01100010  (+98)  
     --------
OF=1 10100011  (-93) <- Wrong! Should be +163

💡 For signed arithmetic: Watch OF for errors!

🔢 Multiplication & Division

When Simple Math Gets Complex

MUL - Unsigned Multiplication

Formats:

Multiplier Multiplicand Product
reg/mem8 AL AX
reg/mem16 AX DX:AX
reg/mem32 EAX EDX:EAX

Example:

mov al, 12       ; multiplicand
mov bl, 15       ; multiplier
mul bl           ; AX = 12 * 15 = 180

🎯 Key Point: Result can be twice the input size!

IMUL - Signed Multiplication Magic

Three Powerful Forms:

  1. Single Operand: IMUL reg/mem (like MUL)
  2. Two Operand: IMUL dest, source (result truncated)
  3. Three Operand: IMUL dest, src1, src2 (most flexible)
; Quick multiplication by 7
imul eax, [x], 7    ; eax = x * 7
mov [y], eax        ; y = result

Division: The Tricky Operation

DIV (Unsigned)

; Divide 1000 by 3
mov dx, 0       ; Clear high
mov ax, 1000    ; Dividend
mov cx, 3       ; Divisor
div cx          ; AX=333, DX=1

IDIV (Signed)

; Divide -125 by 2
mov al, -125    ; Dividend
cbw             ; Sign extend
mov bl, 2       ; Divisor  
idiv bl         ; AL=-62, AH=-1

⚠️ Critical: Always prepare the dividend properly!

Sign Extension Instructions

CBW

Convert Byte to Word

mov al, -50
cbw  ; AX = FF CE

CWD

Convert Word to Dword

mov ax, -1000
cwd  ; DX:AX = sign-extended

CDQ

Convert Dword to Qword

mov eax, -50000
cdq  ; EDX:EAX = sign-extended

🧠 Logic Instructions

Bit-Level Wizardry

The Logic Gang

Instructions:

  • AND - Bitwise AND
  • OR - Bitwise OR
  • XOR - Exclusive OR
  • NOT - Bitwise complement

Truth Tables:

AND: 1&1=1, others=0
OR:  0|0=0, others=1  
XOR: same=0, diff=1
NOT: 1→0, 0→1

Bit Manipulation Techniques

🎯 Clearing Bits (Masking)

mov al, 11100110b    ; Original value
and al, 11111011b    ; Clear bit 2 → 11100010b

🎯 Setting Bits

mov al, 11100010b    ; Original value  
or  al, 00000100b    ; Set bit 2 → 11100110b

🎯 Toggling Bits

mov al, 10010110b    ; Original value
xor al, 00001111b    ; Toggle bits 0-3 → 10011001b

Real-World Bit Operations

Check if Even/Odd:

mov eax, [number]
and eax, 1          ; Test bit 0
; ZF set = even
; ZF clear = odd

Fast setting to zero:

; set EBX to zero
xor  ebx, ebx

Flipping all bits

mov  eax, [number]
xor  eax, -1

💡 Pro Tip: Bit operations are lightning fast!

🗺️ Addressing Modes

Seven Ways to Find Your Data

Memory Addressing Overview

Effective Address = Base + Index×Scale + Displacement

Components:

  • Displacement: Constant offset
  • Base: Pointer register
  • Index: Array subscript
  • Scale: Element size (1,2,4,8)

Sample Data:

section .data
array   dd  10, 20, 30, 40, 50
matrix  dd  1, 2, 3, 4
        dd  5, 6, 7, 8

Mode 1: Direct Addressing

mov eax, [array]        ; Get first element
mov ebx, [array + 4]    ; Get second element

🎯 Use Case: Accessing known, fixed locations

Mode 2: Base Addressing

mov esi, array          ; ESI points to array
mov eax, [esi]          ; Get array[0] = 10
add esi, 4              ; Move to next element
mov ebx, [esi]          ; Get array[1] = 20

🎯 Use Case: Traversing data structures, linked lists

Mode 3: Index Addressing

mov esi, 2              ; Array index
mov eax, [esi*4 + array] ; Get array[2] = 30

Scale Factor Magic:

  • Scale 1: Byte arrays (char[])
  • Scale 2: Word arrays (short[])
  • Scale 4: Dword arrays (int[])
  • Scale 8: Qword arrays (long long[])

Mode 4: Base + Index

Perfect for 2D Arrays!

mov esi, matrix         ; Base address
mov edi, 1              ; Row 1
mov eax, 2              ; Column 2

; Access matrix[1][2]:
mov ebx, [esi + edi*16 + eax*4]  ; Result: 7

💡 Calculation: Row×(columns×element_size) + Column×element_size

Advanced Example: Student Records

; Student record: ID(4), Grade(4), Age(4), GPA(4) = 16 bytes total
students    dd  1001, 85, 20, 35    ; Student 0
            dd  1002, 92, 19, 38    ; Student 1  
            dd  1003, 78, 21, 32    ; Student 2

; Access student[1].grade:
mov esi, students       ; Base address
mov edi, 1              ; Student index
mov eax, [esi + edi*16 + 4]  ; Grade at offset 4

🎯 Result: EAX = 92 (student 1’s grade)

🎮 Interactive Challenge

Convert this C++ code to Assembly:

int result = (array[i] + array[j]) * 2;

Solution:

mov esi, i
mov edi, j
mov eax, [array + esi*4]    ; array[i]
add eax, [array + edi*4]    ; + array[j]
shl eax, 1                  ; * 2 (or: add eax, eax)
mov [result], eax

🧪 Lab Exercise: Bit Flag System

Create a permission system using bits:

; Bit positions:
; 0: Read permission
; 1: Write permission  
; 2: Execute permission
; 3: Admin permission

mov al, 0           ; Start with no permissions
; Grant read & write:
or al, 00000011b    ; Set bits 0,1

; Check if admin:
and al, 00001000b   ; Test bit 3
; ZF tells us the result

🎯 Performance Tips

  • Use INC/DEC instead of ADD/SUB 1 (smaller instruction)
  • Use LEA for complex address calculations
  • Use XOR reg, reg to clear registers (faster than MOV)
  • Test with AND rather than CMP when checking bits

💡 Remember: Modern CPUs are smart, but good habits matter!
